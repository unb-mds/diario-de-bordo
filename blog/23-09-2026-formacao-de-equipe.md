##  Descreva como está sendo o processo de organização da sua equipe até agora — papéis, expectativas, primeiras decisões.

Durante as primeiras semanas já foi definido o SCRUM MASTER, além disso foi dividido o que cada membro estudaria (Git e Github, Metodologia Ágeis, Banco de dados, Docker e Arquitetura) e posteriomente a implementação foi dividida em 3 frentes, sendo: backend, frontend e banco de dados. Durante a primeira semana fiquei com o estudo de Git e Github e tive um primeiro contato com muitas coisas, principalmente o Gitflow, depois, passei para o backend. Com a divisão, consegui focar os estudos para o backend e perceber o que ainda preciso desenvolver para realizar minhas tarefas.

## Que sensações ou pensamentos você tem tido em relação ao início desta disciplina e ao projeto que vocês vão desenvolver?

Ansiedade e Curiosidade, afinal foi a primeira matéria que tive um contato mais próximo com um software real, assim tive muito contato com novos assuntos, seja de implementação ou até de organização como Git e Github. Assim, naturalmente gera um pouco de insegurança, pois o primeiro contato com novos processos e assuntos gera um pouco de estranheza. Ao mesmo tempo ver o projeto tomando forma desperta a curiosidade e satisfação. Ainda preciso de tempo e prática para me familiarizar com essas ferramentas. Quero continuar aprendendo e ganhar mais confiança.

## Que conhecimentos, ferramentas ou práticas você sente que já domina, e quais ainda são novidade para você neste momento?

O processo de Gitflow foi uma novidade, afinal já havia utilizado o Github anteriormente, mas nada com um fluxo organizado de branches. O Scrum também foi uma novidade, em especial as sprints e as reuniões. Além disso, durante o backend tive o primeiro contato com contratos e APIs, conceitos que de início tive dificuldade de entender. Ainda preciso praticar a organização das branches e entender melhor os contratos de API para realizar as próximas tarefas com mais segurança.
